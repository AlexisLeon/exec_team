---

Help make a decision and write it down. $ARGUMENTS

1. As the `cofounder` agent, first check whether this is actually a decision or a
   question that's already settled — search `company/decisions/` for related entries.
   If it's settled, say so and stop. Relitigating is a time leak.
2. State the real question. Reframe it if the one asked is the wrong one.
3. Lay out the genuine options — including "do nothing," which is always on the table
   and is usually underrated. Two or three, not a survey.
4. For each: what has to be true for it to be right, and what it costs.
5. Give your recommendation. Commit to one. A chairman who won't pick is useless.
6. Pressure-test it once: what's the strongest argument against your own pick?
7. Write `company/decisions/YYYY-MM-DD-slug.md` using `_template.md`. The
   **"What we expect to happen"** section must be falsifiable — a number and a date —
   and set a `review_on` date so `/weekly` picks it up.
