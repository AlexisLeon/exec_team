# Customers

The highest-value folder in this repo. Raw material, not summaries.

**What goes here:** call transcripts, discovery notes, support threads worth keeping,
churn post-mortems, lost-deal notes, feature requests in the customer's own words,
pricing objections verbatim.

**Naming:** `YYYY-MM-DD-company-slug.md` (e.g. `2026-10-27-clinica-dental-sur.md`)

**Rules:**
- Paste raw. Do not clean up their language — their exact words are the asset.
- One file per conversation, not per company. The second call is new information.
- Lost and churned are more valuable than won. Write those first.
- Never delete. If something turns out to be wrong, append a correction.

Use `/call` after any customer conversation to file one of these properly.
